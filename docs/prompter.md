# Телепромптер — шпаргалка

Сценарии — обычные `.md` / `.txt` в `~/Documents/prompter` (`prompter.dir`).
Открыть: лаунчер `!prompt` (файлы, свежие сверху, + «из буфера») или
`qs -c flicker ipc call prompter open <путь>` / `… clipboard`.

## Разметка

| Пишешь | Что будет |
|---|---|
| `# Заголовок` … `######` | заголовок (крупнее по уровню), читается вслух |
| пустая строка | новый абзац |
| `- пункт`, `1. пункт` | список |
| `**жирный**`, `*курсив*` | стиль, читается как обычный текст |
| `==текст==` | подсветка (жёлтая по умолчанию) |
| `==🔴текст==` 🟠 🟡 🟢 🔵 🟣 | цветная подсветка, кружок не показывается |
| `---` | разделитель |
| `[ремарка]` | подсказка себе: синий курсив, **не читается** |
| `> цитата`, `<!-- … -->` | тоже ремарка, не читается |
| `` `код` ``, блок ```` ``` ```` | моноширинный, не читается |
| `%%комментарий%%` | скрыт совсем (как в Obsidian) |
| `[текст](url)` | только «текст» |
| `\*`, `\=`, `\[` | символ как есть, без разметки |

Ремарки и код голосовой режим пропускает, режим auto проскакивает их сразу.
Незакрытые `**` / `==` действуют до конца абзаца.

## Картинки

```
Были построены 3 функции …

![](img/shot01.png) ![подпись](img/shot02.png)     ← отсюда картинки справа

Рассмотрим первую функцию … %%/img%% дальше …      ← здесь скрываются
```

- Абзац только из `![…](…)` — картинки в панели справа (остров расширяется).
  Видны с этого места до `%%/img%%`; без метки — до следующих картинок,
  заголовка или `---`.
- Пути — относительно папки сценария; можно абсолютные, `~/…`, `file://`.
- `http(s)` не грузится, из буфера обмена относительные пути не найти —
  вместо картинки будет `[подпись]` ремаркой. Картинка посреди текста — тоже
  ремарка.
- Не загрузилась — в панели подпись или имя файла.

## Режимы и управление

- **voice** — курсор идёт за голосом; ушёл от текста — найдёт по первым словам.
- **auto** — ровный темп `prompter.wpm` (130 слов/мин).
- **manual** — только руками.

Клавиши (после клика по острову): `Space` пауза · `↑`/`↓` назад/вперёд ·
`PgUp`/`PgDn` по блокам · `M` режим · `Esc` закрыть. Колесо — сдвиг курсора.
Кнопки внизу: статус (нажатие — пауза), режим (нажатие — следующий).
Закрыть — свайп вверх. Позиция в каждом файле запоминается; правки файла
подхватываются на лету.

IPC `prompter`: `open <путь>`, `clipboard`, `text <строка>`, `show`, `close`,
`toggle`, `pause`, `mode voice|auto|manual`, `move <слов>`, `next`, `prev`,
`status`.

## Настройки (`config.json` → `prompter`)

`mode`, `language` (`auto` — по алфавиту текста), `wpm`, `width`/`height`,
`fontSize`, `readLine` (где линия чтения, доля высоты), `imagePanelWidth`,
`highlightAlpha` / `highlightReadAlpha` (прозрачность подсветки).
