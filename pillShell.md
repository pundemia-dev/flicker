## Контекст

Ты реализуешь системный shell для Linux на Quickshell/QML. В качестве референса
у тебя есть репозиторий `pShell` (скачай его - https://github.com/pundemia-dev/pShell.git). Из него ты берёшь:
- Логику сервисов (D-Bus notifications, MPRIS, PipeWire, NetworkManager, UPower)
- Логику ext-session-lock + PAM
- Паттерн Config (JsonObject adapter, hot-reload из ~/.config/)
- IPC-паттерны для Niri
- Общую структуру Quickshell-приложения (WlrLayershell, IpcHandler, etc.)

Из pShell ты НЕ берёшь:
- SDF шейдеры (Caelestia.Blobs) — их нет вообще
- Rails system, WindowSlot, BackgroundsManager
- InteractionManager (8 зон)
- Множественные менеджеры видимости
- Компоненты интерфейса (StyledRect, ButtonBase, etc.) — UI пишется с нуля

## Главная концепция

Вместо традиционной панели/бара — ЕДИНЫЙ Dynamic Island в верхней части экрана.
Один объект на монитор. Все функции shell живут внутри этого объекта.

## Состояния острова

### 1. Island (default)
Компактный тёмный остров (высота ~36px, скругление ~22px).
Внутри: фоновые индикаторы + часы по центру.
По бокам: дуги (wifi слева, battery справа).

### 2. Minimal
Тонкая полупрозрачная полоска (~6px) с блюром.
Активируется при:
- Полноэкранном режиме активного окна
- Зажатии ЛКМ на острове + перемещение курсора вверх за его пределы
Возврат в Island:
- Свайп вниз из зоны полоски
- По таймеру бездействия (3 секунды после последнего взаимодействия)

Модули, открытые свайпом/слайдом ИЗ состояния Minimal (например, в fullscreen),
по истечении таймера бездействия возвращаются не в Island, а обратно в Minimal —
то есть модуль возвращается в то состояние, из которого был открыт.

Активная зона захвата ЛКМ в состоянии Minimal — не только сама полоска,
а вся область от полоски (включительно) до верхнего края экрана.

В минимале остров продолжает отслеживать события.
Уведомления в минимале становятся бегущей строкой (тикер).

### 3. Module
Остров расширяется, показывая полноценный интерфейс модуля.
Индикаторы при этом не умирают — они скрыты под модулем.
При закрытии модуля остров возвращается к предыдущему состоянию.
Если в очереди есть ожидающие уведомления — раскрывается следующее.

## Переходы между состояниями

Все переходы анимируются пружинами (не линейные, не ease).
Единая анимация для всех морфингов: изменение размера, скругления, контента.
Контент меняется через fade + лёгкий scale (старый уходит, новый приходит).
При переходе в/из Minimal — сначала появляется/исчезает блюр, затем контент.

Остров хранит previousState перед открытием любого модуля/индикатора и всегда
возвращается именно в него (Island или Minimal), а не безусловно в Island.

## Фоновые индикаторы

Индикаторы — маленькие элементы ВНУТРИ острова, не отдельные окна.
Могут существовать одновременно несколько.
Примеры: музыка, микрофон, запись экрана, диктовка, таймер, хотспот.

### Порядок в острове:
[ левые индикаторы | ЧАСЫ | правые индикаторы ]

### Левые: музыка, диктовка, микрофон (и будущие)
### Правые: запись, таймер, хотспот (и будущие)

### Правила:
- При нехватке места — индикаторы с низким приоритетом скрываются
- Индикатор микрофона НЕ срабатывает на диктовку и запись экрана
- Индикатор микрофона при наведении показывает имя приложения (через fade справа)
- Равное расстояние между индикаторами (настраиваемый множитель indicatorSpacingFactor)
- Равное расстояние от индикаторов до левого/правого края острова
  (отдельный настраиваемый множитель edgePaddingFactor, независимый от первого)

### Пример layout и приоритеты

Пример порядка индикаторов в острове:
[ microphone | music | dictation | time | recording | timer ]

Планируемые к добавлению индикаторы (через Registry.qml, без изменения Island):
VPN, Bluetooth device connection, AirPlay, file transfer, timer, alarm,
clipboard operation, download/upload, battery charging, low battery,
updates (при старте системы), package installation, system errors, network activity.

Каждый индикатор в Registry декларирует приоритет — индикаторы с более высоким
приоритетом вытесняют менее приоритетные при нехватке места в острове.

### Конкретные индикаторы:

**Музыка**: круглая обложка альбома (32px). При клике — раскрывается модуль плеера.
При наведении — тоже раскрывается.

**Запись экрана**: часы получают красную подложку. При клике — две кнопки (стоп/отмена).
Анимация появления: красная плашка приезжает сверху через fade, увеличиваясь
с половины размера до полного, с иконкой стоп. Потом иконка исчезает, время появляется.

Остановка записи: красная подложка вместе с часами уменьшается и уезжает
вверх за пределы острова (fade). Остров при этом НЕ меняет своих размеров.
Параллельно через fade появляется время на своём обычном месте и в обычном размере.

**Хотспот**: то же что запись, но зелёная подложка и другая иконка.
При клике по зелёной подложке — то же самое поведение, что и при клике
по красной подложке записи: весь контент бара заменяется двумя кнопками
(отменить / остановить).

**Микрофон**: оранжевый кружок (8px) слева с краю. Не интерактивный модуль,
просто индикатор. При наведении справа появляется текст с именем приложения.

**Диктовка**: аудиовизуализатор. Появляется через fade от центра,
остров расширяется по мере проявления. Позиция: после музыкального индикатора,
перед часами.

## Дуги по бокам

Слева от острова: дуга жёлтого цвета — уровень сигнала WiFi.
Справа от острова: дуга (зелёная/жёлтая/красная) — заряд батареи.
Дуги идут от низа, заполненность = уровень.
При переходе острова в другое состояние — дуги уходят под остров с fade.
При отсутствии WiFi или батареи — дуга скрывается.
Индикатор воркспейсов тоже вписать в дуги или рядом.

## Модули

### Notifications
При появлении уведомления остров расширяется и показывает его.
В полноэкранном режиме: уведомление становится тикером в тонкой полоске.
Если модуль уже открыт: уведомление идёт в очередь.
После закрытия текущего модуля — раскрывается следующее уведомление из очереди.
Тосты: показываются только важные (по urgency из D-Bus).

### Launcher
Полностью заменяет содержимое острова.
[ time ] → [ search field + application results ]
Вызов по хоткею. Закрытие — возврат к предыдущему состоянию.

### Capture
Особая логика:
1. Остров "ворует" свой фон: контент исчезает через fade, поверх появляется блюр.
2. Фон превращается в квадрат со скруглениями.
3. Квадрат перемещается по дуге к курсору мыши.
4. Внутри квадрата — иконка состояния, преследующая курсор (с ускорением,
   точка чуть правее-ниже курсора).
5. Параллельно создаётся ВТОРОЙ инстанс острова: минимальная полоска выезжает
   из-за границы экрана (анимация appearFromEdge — та же, что используется
   при старте shell). Если активное приложение на этом мониторе НЕ в fullscreen —
   полоска превращается в обычный Island (бар). Если fullscreen — остаётся Minimal.
6. Параллельно: экран затемняется, появляется перекрестие от границ через курсор.

Функции захвата:
- Screenshot
- Screen recording
- Выбор области
- Захват области для нейросети

Во время записи: остров показывает время на красной подложке (см. индикатор записи).

### Quick Settings
Открытие: свайп справа от острова или хоткей.
Остров расширяется вниз.
Содержимое:
- Wi-Fi, Bluetooth, VPN, Hotspot
- Volume slider, Brightness slider
- Microphone toggle
- Do Not Disturb
- Media controls
- Другие системные переключатели

### Lock
Вызывает блокировку через ext-session-lock протокол.
Рисует локскрин.
Остров не должен оставлять интерактивные элементы поверх лока.
При активации лока — остров скрывается.

### OSD
Заменяет контент острова иконкой + состояние.
Иконка слева, полоска/значение справа.
Для: громкости, яркости, микрофона, медиа.
НЕ показывается при изменении через QuickSettings.
Появляется только при изменении клавишами.
Автоматически возвращается к предыдущему состоянию.

### Dictation
Запись микрофона + speech-to-text.
Во время диктовки: аудиовизуализатор появляется слева от часов.
Если играет музыка — визуализатор правее музыкального индикатора.
Справа остаются системные индикаторы.
Появление: от центра визуализатора, остров расширяется.

### LocalSend
Передача файлов.
Временная файловая корзина / drop zone, доступная через остров.
При драге файла на остров — появляется зона сброса.

### Corners
Скруглённые углы по краям монитора. Всегда активны.

## Shared Element Transitions

При переходе из фонового состояния в модуль (например, клик по обложке альбома
→ модуль плеера), элемент НЕ умирает. Он перемещается в новое местоположение.

Механика:
- Элемент перепарентится в глобальный TransitionLayer (поверх всего)
- Анимация по контракту: каждый элемент сам декларирует какие свойства анимируются
- Это может быть: позиция, размер, скругление, цвет, прозрачность, что угодно
- По завершении анимации элемент перепарентится в модуль
- Остальной контент модуля появляется через fade

Контракт декларируется на самом элементе:
```
sharedTransition: {
    target: "player",
    properties: {
        width: 180,
        height: 180,
        radius: Theme.radiusLarge
    },
    duration: 300,
    curve: springCurve
}
```

## Presentation Mode

При зажатии ЛКМ по бару и перемещении курсора вверх от бара за пределы острова —
остров переходит в состояние minimal.

## Мультикомпозиторность

Shell должен работать на:
- Niri
- Hyprland
- DriftWM

Абстракция:
- `compositor/Compositor.qml` — фасад
- `compositor/Detect.qml` — автоопределение активного WM
- `compositor/backends/Niri.qml`
- `compositor/backends/Hyprland.qml`
- `compositor/backends/Drift.qml`

Фасад предоставляет:
- `.fullscreen` (bool)
- `.workspace` (int)
- `.workspaceCount` (int)
- `.grabFocus()` / `.releaseFocus()`
- `.spawn(cmd)`
- `.screenshot(region)`
- `.startRecording(region)` / `.stopRecording()`

Весь остальной код обращается только к фасаду, не зная какой WM активен.

- Минималистичный остров в духе iOS

## Технологические решения

- Рендеринг: чистый QML, Rectangle + radius + пружины. БЕЗ шейдеров.
- Блюр: `MultiEffect` (Qt 6.5+) или `FastBlur` — нативные эффекты.
- Анимации: `SpringAnimation` везде. Единая физика.
- Иконки: Tabler (variable font).
- Конфиг: JSON файл + QML adapter (паттерн из pShell).
- D-Bus: для уведомлений, MPRIS, NetworkManager, UPower.
- PipeWire: для аудио и микрофона.
- Скриншоты: `grim` + `slurp` (wlroots-стандарт).
- Запись: `wf-recorder`.
- Лок: `ext-session-lock` протокол + PAM.
- Анимация appearFromEdge (выезд минимальной полоски из-за края экрана с
превращением в бар) — переиспользуемый примитив ContentSwap/Island,
используется как при старте shell, так и при создании второго инстанса в Capture.

## Что брать из pShell (референс)

- `services/Notifs.qml` → логика D-Bus notification server
- `services/Players.qml` → MPRIS
- `services/Audio.qml` → PipeWire (без CavaProvider, если не нужен визуализатор)
- `services/Network.qml` → NetworkManager
- `modules/lock/` → ext-session-lock + PAM + handshake
- `services/Niri.qml` → IPC паттерны (адаптировать в `compositor/backends/Niri.qml`)
- `config/Config.qml` → паттерн JsonObject adapter

## Правила реализации

1. Один файл = одна ответственность. Не более 200 строк.
2. Никаких хардкод-значений. Всё через Theme.qml токены.
3. Пружинные анимации везде. Никаких линейных.
4. Индикаторы не создают окон. Они живут внутри острова.
5. Модули не создают панелей. Они расширяют остров.
6. Переходы между состояниями — через ContentSwap (fade + scale).
7. SharedElement — через перепарентинг в TransitionLayer, не через снапшоты.
8. Компромисс: лучше меньше кода и понятнее, чем больше и "гибче".
9. Расширяемость: новый индикатор = один файл + регистрация в Registry.

### 1. Island (default / bar)
Компактный тёмный остров. Внутри: фоновые индикаторы + часы по центру.
По бокам — дуги (wifi слева, battery справа).

### 2. Minimal
Тонкая полупрозрачная полоска **серого цвета**, с блюром.
Активируется при:
- Полноэкранном режиме активного окна
- Зажатии ЛКМ на баре + перемещение курсора вверх за пределы острова
  (presentation mode)

Возврат в Island:
- Свайп вниз из зоны полоски
- По таймеру бездействия (значение настраивается, дефолт — 3 секунды
  после последнего взаимодействия)

**Раскрытие острова удержанием ЛКМ.** Зажатие ЛКМ в активной зоне minimal
(от самой полоски, включительно, до верхнего края экрана) временно **раскрывает
остров обратно в состояние Island (bar)** — через тот же переход blur→fade,
что используется во всех остальных переходах в/из Minimal. Пока кнопка
удерживается, остров остаётся раскрытым. При отпускании кнопки (без
дополнительного жеста) остров возвращается в Minimal. Это отдельный жест от
presentation mode (тот работает наоборот — сворачивает bar в Minimal через drag
вверх) и отдельный от жестов открытия конкретных модулей (Dashboard,
Notification Center, Quick Settings) — см. ниже.

Модули, открытые свайпом/жестом ИЗ состояния Minimal (например, в fullscreen),
по истечении таймера бездействия возвращаются не в Island, а обратно в Minimal —
то есть модуль возвращается в то состояние, из которого был открыт
(previousState).

В Minimal остров продолжает отслеживать все системные события.

**Уведомления в Minimal.** При появлении уведомления, если активное приложение
в fullscreen (следовательно остров в Minimal), полоска Minimal **разворачивается
в полноценный обычный бар** (через стандартный переход blur→fade), и уведомление
скроллится текстом (тикером) внутри этого развернутого бара, не замещая
содержимое так, как это происходит в обычном режиме. Контент острова (часы,
индикаторы) при этом не замещается уведомлением — тикер идёт поверх/рядом с
раскрытым баром. После завершения показа тикера бар возвращается обратно в
Minimal (via blur→fade).

Когда приложение НЕ в fullscreen (остров в состоянии Island) — уведомление
полностью замещает контент острова, как обычный модуль.

### 3. Module
Остров расширяется, показывая полноценный интерфейс модуля.
Фоновые индикаторы, не участвующие в анимации открытия, скрываются через тот же
паттерн **blur→fade** (но в определенной очередности - сперва самые ближние к индикатору, что останется (перетечет в модуль), и по удалению от него. если такового индикатора нет, то от центрального индикатора), что используется во всех переходах (см. раздел
«Единая анимация переходов»), а не через простой fade.
При закрытии модуля остров возвращается к previousState (Island или Minimal).
Если в очереди есть ожидающие уведомления — раскрывается следующее (см.
«Notifications» и «Очередь уведомлений»).

## Единая анимация переходов (важно, единый паттерн для ВСЕХ случаев)

Один и тот же паттерн анимации используется **во всех** морфингах острова:

- Island ↔ Minimal
- Module ↔ Minimal (открытие/закрытие модуля, когда остров сейчас в Minimal)
- Module ↔ Island (открытие/закрытие модуля из состояния бара)
- Minimal ↔ Minimal-развёрнутый-в-бар для тикера уведомлений
- Появление второго инстанса острова в Capture (appearFromEdge)
- Скрытие фоновых индикаторов, не участвующих в текущей анимации-переходе

Последовательность: **сначала появляется/усиливается блюр, с небольшой
задержкой — fade контента.** При обратном переходе — симметрично: fade
контента, затем спад блюра. Это единственный паттерн для смены контента —
никакого отдельного «fade + scale»; scale в переходах не используется нигде,
кроме отдельно описанных частных случаев (например, движение элемента в
Shared Element Transition, которое устроено иначе — через перепарентинг, а
не через ContentSwap).

Все переходы анимируются пружинами (не линейные, не ease) в части перемещения/
размера; сам fade/blur — по времени с настраиваемой задержкой между стадиями.

Остров хранит `previousState` перед открытием любого модуля/индикатора и
возвращается именно в него, а не безусловно в Island.

## Фоновые индикаторы

Индикаторы — маленькие элементы ВНУТРИ острова, не отдельные окна.
Могут существовать одновременно несколько.

### Порядок в острове:
`[ левые индикаторы | ЧАСЫ | правые индикаторы ]`

### Левые: музыка, диктовка, микрофон (и будущие)
### Правые: запись, таймер, хотспот (и будущие)

### Правила:
- При нехватке места — индикаторы с низким приоритетом скрываются
  (через blur→fade)
- Индикатор микрофона НЕ срабатывает на диктовку и запись экрана
- Индикатор микрофона при наведении показывает имя приложения (fade справа,
  остров расширяется по мере проявления текста)
- Равное расстояние между индикаторами — множитель `indicatorSpacingFactor`
- Равное расстояние от индикаторов до левого/правого края острова — отдельный
  множитель `edgePaddingFactor`, независимый от первого
- Оба множителя вычисляются относительно фактического текущего размера острова

### Пример layout и приоритеты

```
[ microphone | music | dictation | time | recording | timer ]
```

Планируемые к добавлению индикаторы (через `Registry.qml`, без изменения Island):
VPN, Bluetooth device connection, AirPlay, file transfer, timer, alarm,
clipboard operation, download/upload, battery charging, low battery,
updates (при старте системы), package installation, system errors, network
activity.

Каждый индикатор в Registry декларирует приоритет — индикаторы с более высоким
приоритетом вытесняют менее приоритетные при нехватке места.

### Конкретные индикаторы

**Музыка**: круглая обложка альбома. При клике или наведении — раскрывается
полноценный модуль плеера через Shared Element Transition (обложка
перемещается и увеличивается в левую часть модуля, остальной контент модуля
появляется через fade).

**Запись экрана**: часы получают красную подложку.
Появление: красная плашка приезжает сверху через fade, увеличиваясь с
половины размера до полного, с иконкой «стоп» на месте часов; иконка исчезает
через fade, время появляется через fade.
Остановка: красная подложка вместе с часами уменьшается и уезжает вверх за
пределы острова (fade). Остров при этом **не меняет своих размеров**.
Параллельно через fade появляется время на обычном месте в обычном размере.
При клике по красной подложке — контент бара замещается двумя кнопками
(отменить / остановить).

**Хотспот**: та же механика, что и запись, но подложка зелёная, иконка другая.
При клике по зелёной подложке — то же поведение, что и по красной (замена
контента бара на кнопки отменить/остановить).

**Микрофон**: небольшой оранжевый кружок слева с краю острова. Не интерактивный
модуль — чистый индикатор состояния. При наведении справа от него появляется
текст (fade справа) с именем использующего приложения, остров расширяется по
мере проявления текста.

**Диктовка**: аудиовизуализатор. Появляется через fade от центра визуализатора
наружу, остров расширяется по мере его проявления. Позиция: после музыкального
индикатора, перед часами. Если музыка не играет — сразу слева от часов.

## Дуги по бокам

Слева от острова: дуга жёлтого цвета — уровень сигнала WiFi.
Справа от острова: дуга (зелёная/жёлтая/красная по уровню) — заряд батареи.
Дуги видны только в состоянии Island (bar), заполненность растёт снизу вверх.
При переходе острова в другое состояние — дуги уходят под остров с fade в
цвет фона (background color), обратно появляются той же анимацией.
При отсутствии WiFi или батареи — соответствующая дуга скрыта.
Индикатор воркспейсов аккуратно вписывается в область дуг или рядом с ними
(точное расположение — на усмотрение реализации, не должно визуально спорить
с дугами).

## Модули

### Notifications (уведомления)

Два независимых сценария использования модуля:

**1. Автоматический показ входящего уведомления.**
При появлении уведомления остров расширяется и показывает его (в Island — с
полной заменой контента; в Minimal — тикер в развёрнутом баре, см. выше).
Если модуль уже открыт — новое уведомление становится в **очередь (FIFO)**:
показывается в порядке поступления после закрытия текущего модуля/уведомления.
%3E Примечание: в очереди решено использовать FIFO как более привычную UX-модель
> для потока уведомлений. Если нужна была семантика LIFO-стека (последнее
> уведомление показывается первым), это нужно явно поменять — сообщите,
> и логика очереди инвертируется.

После закрытия текущего модуля, если в очереди есть уведомления — раскрывается
следующее.

Тосты (низкоприоритетные, не прерывающие) показываются только важные — по
уровню urgency, заданному в самом уведомлении (D-Bus).

**2. Notification Center (по требованию, история).**
Открывается жестом: зажатие ЛКМ **в зоне слева от острова** (зеркально
зоне Quick Settings справа) + перетаскивание курсора вниз за пределы бара.
Внутри — история уведомлений, представленная компактными полосками
(дефолтный размер: высота 5px, ширина 10px, настраивается), выстроенными по
времени поступления. При взаимодействии (клике по полоске) — раскрывается
полное содержимое конкретного уведомления.
Notification Center — это отдельный вход в тот же модуль `notifications`,
а не отдельный модуль-папка: он переиспользует ту же инфраструктуру очереди
и рендеринга уведомлений, но в режиме просмотра истории, а не потока.

### Dashboard (новый модуль)

Открывается жестом: зажатие ЛКМ **непосредственно на индикаторе часов** +
перетаскивание курсора мыши вниз за пределы бара.
Остров расширяется вниз (аналогично механике Quick Settings и Notification
Center — «выдвижной ящик», следующий за курсором при перетаскивании, со
снэпом в открытое состояние при превышении порога `dashboardDragThreshold`).
Содержимое дашборда — состав виджетов уточняется отдельно (не определён в
исходном ТЗ), но архитектурно модуль должен:
- Полностью замещать содержимое острова, пока открыт
- Регистрироваться в `ModuleHost` как любой другой модуль
- Возвращать остров в previousState при закрытии (свайп вверх / клик мимо /
  хоткей)

### LocalSend

Передача файлов. Временная файловая корзина / drop zone, доступная
непосредственно через остров. При драге файла на остров — появляется зона
сброса для последующей передачи.

### Launcher

Полностью заменяет содержимое острова.
`[ time ] → [ search field + application results ]`
Вызов по хоткею. Закрытие — возврат к previousState.

### Capture

Особая логика:
1. Остров «ворует» свой фон: контент исчезает через fade, поверх появляется
   блюр (порядок как в общем паттерне: блюр → fade).
2. Фон превращается в квадрат со скруглениями.
3. Квадрат перемещается по дуге к курсору мыши.
4. Внутри квадрата — иконка состояния модуля захвата, преследующая курсор
   (с ускорением, целится в точку чуть правее-ниже курсора).
5. Параллельно создаётся ВТОРОЙ инстанс острова: минимальная полоска
   выезжает из-за границы экрана (анимация `appearFromEdge` — тот же
   переиспользуемый примитив, что и при старте shell). Если активное
   приложение на этом мониторе НЕ в fullscreen — полоска превращается в
   обычный Island (bar) через blur→fade. Если fullscreen — остаётся Minimal.
6. Параллельно: экран немного затемняется через fade, появляется
   перекрестие от границ экрана через курсор (тоже через fade).

Функции захвата (единый модуль):
- Screenshot
- Screen recording
- Выбор области
- Захват области для распознавания через нейросеть

Во время записи — см. индикатор «Запись экрана» выше (красная подложка на
часах).

Capture логически работает поперёк всех мониторов — второй инстанс острова,
перекрестие и область выбора не ограничены одним экраном, в отличие от
остальных модулей.

### Quick Settings

Открытие: свайп/drag справа от острова вниз (аналогично Notification Center,
но с противоположной стороны) либо отдельный hotkey (требует IPC).
Остров расширяется вниз, замещая контент.
Содержимое:
- Wi-Fi, Bluetooth, VPN, Hotspot
- Volume slider, Brightness slider
- Microphone toggle
- Do Not Disturb
- Media controls
- Другие системные переключатели

### Lock

Вызывает блокировку через `ext-session-lock` протокол + PAM, рисует
собственный lockscreen.
Остров не должен оставлять интерактивные элементы поверх lockscreen при
активном локе.

### OSD

Заменяет весь контент острова: иконка слева, значение/полоска справа.
Используется для: громкости, яркости, микрофона, медиа-параметров.
Появляется **только** при изменении через клавиши/хоткеи — НЕ показывается,
если изменение произошло через Quick Settings.
Автоматически возвращается к previousState по таймеру.

### Dictation

Запись микрофона + speech-to-text.
Во время диктовки аудиовизуализатор появляется слева от часов (после
музыкального индикатора, если он есть). Появление — fade от центра
визуализатора наружу, остров расширяется по мере проявления.

### Corners

Скруглённые углы по краям монитора. Всегда активны, не зависят от состояния
острова.

## Shared Element Transitions

При переходе из фонового индикатора в модуль (например, клик по обложке
альбома → модуль плеера) элемент НЕ умирает — он перемещается в новое
местоположение через `ParallelAnimation`.

Механика:
- Элемент перепарентится в глобальный `TransitionLayer` (поверх всего)
- Анимация по контракту: каждый элемент декларирует, какие свойства
  анимируются (позиция, размер, радиус, цвет, прозрачность — что угодно)
- По завершении анимации элемент перепарентится в модуль
- Остальной контент модуля появляется через fade

Контракт декларируется на самом элементе:
```qml
sharedTransition: {
    target: "player",
    properties: {
        width: 180,
        height: 180,
        radius: Theme.radiusLarge
    },
    duration: 300,
    curve: springCurve
}
```

Это отдельный, самостоятельный механизм анимации — он не заменяет и не
смешивается с паттерном blur→fade, описанным выше для смены состояний острова.

## Presentation Mode

При зажатии ЛКМ по бару (состояние Island) и перемещении курсора вверх от
бара за пределы острова — остров переходит в состояние Minimal (через общий
паттерн blur→fade).

| Жест | Откуда | Что открывает |
|---|---|---|
| Hold ЛКМ на баре + drag вверх за пределы острова | Island | → Minimal (presentation mode) |
| Hold ЛКМ в зоне (полоска…верх экрана) | Minimal | Временное раскрытие в Island, пока держится кнопка |
| Hold ЛКМ на индикаторе часов + drag вниз за пределы бара | Island | Dashboard |
| Hold ЛКМ слева от острова + drag вниз | Island | Notification Center |
| Hold ЛКМ / drag справа от острова + drag вниз | Island | Quick Settings |
| Hotkey | Любое | Launcher, Quick Settings (альтернативный вызов), Capture |

пороги драга для открытия) должны быть настраиваемыми — см. следующий раздел.

## Настройки (Config)

Все ключевые размеры и пороги должны быть вынесены в конфиг
(`config/config.json` + `Config.qml`, hot-reload), а не хардкожены. Минимальный
набор, обязательный к вынесению:

- Высота/радиус острова в состоянии Island
- Высота/непрозрачность/радиус blur полоски в состоянии Minimal
- Таймаут авто-возврата из Minimal-раскрытия / из модулей, открытых из Minimal
- Размеры и позиция активной зоны minimal (от полоски до верха экрана)
- Размеры (ширина/высота хитбокса) зоны свайпа/drag для Quick Settings
  (справа от острова)
- Размеры (ширина/высота хитбокса) зоны свайпа/drag для Notification Center
  (слева от острова)
- Порог драга (drag threshold) для открытия Dashboard с часов
- Порог драга для открытия Notification Center и Quick Settings
- Размер полосок истории в Notification Center (дефолт 5×10px)
- `indicatorSpacingFactor` и `edgePaddingFactor`
- Длительность и задержка стадий blur→fade (для обеих стадий отдельно)
- Диаметр обложки плеера, диаметр кружка микрофона
- Радиусы дуг, их ширина/толщина
- Свитч полного отключения блюра (по всему shell)

## Визуальная концепция

- Минималистичный остров в духе iOS
- Компактный тёмный объект в верхней части экрана
- Нет: верхнего бара, дока, постоянных виджетов по краям, градиентов ради
  градиентов, чрезмерного свечения, большого количества декоративных
  элементов
- Анимации: короткие, плавные, пружинные (перемещение/размер) + двухстадийный
  blur→fade (появление/смена контента) — единый паттерн везде
- На каждый монитор — свой инстанс острова
- Модули открываются только на текущем мониторе, ЗА ИСКЛЮЧЕНИЕМ Capture
- Свитч в настройках для полного отключения блюра

## Технологические решения

- Рендеринг: чистый QML, Rectangle + radius + пружины. БЕЗ шейдеров.
- Блюр: `MultiEffect` (Qt 6.5+) или `FastBlur` — нативные эффекты.
- Анимации: `SpringAnimation` для перемещения/размера, двухстадийный
  blur→fade для смены контента (см. «Единая анимация переходов»).
- Иконки: Tabler (variable font).
- Конфиг: JSON файл + QML adapter (паттерн из pShell), все размеры и пороги
  из раздела «Настройки» — вынесены туда же.
- D-Bus: для уведомлений, MPRIS, NetworkManager, UPower.
- PipeWire: для аудио и микрофона.
- Скриншоты: `grim` + `slurp` (wlroots-стандарт).
- Запись: `wf-recorder`.
- Лок: `ext-session-lock` протокол + PAM.
- `appearFromEdge` (выезд минимальной полоски из-за края экрана с
  превращением в бар) — переиспользуемый примитив ContentSwap/Island,
  используется и при старте shell, и при создании второго инстанса в Capture.

## Что брать из pShell (референс)

- `services/Notifs.qml` → логика D-Bus notification server
- `services/Players.qml` → MPRIS
- `services/Audio.qml` → PipeWire (без CavaProvider, если не нужен
  визуализатор целиком)
- `services/Network.qml` → NetworkManager
- `modules/lock/` → ext-session-lock + PAM + handshake
- `services/Niri.qml` → IPC паттерны (адаптировать в
  `compositor/backends/Niri.qml`)
- `config/Config.qml` → паттерн JsonObject adapter

## Правила реализации

1. Один файл = одна ответственность. Ориентир — не более ~200 строк
   (не жёсткий лимит, но сигнал к разбиению файла).
2. Никаких хардкод-значений размеров/порогов. Всё через `Theme.qml` /
   `Config.qml`.
3. Пружинные анимации для перемещения/размера. Blur→fade — для смены
   контента. Никаких линейных transitions.
4. Индикаторы не создают окон. Они живут внутри острова.
5. Модули не создают панелей. Они расширяют остров.
6. Переходы между состояниями — только через `ContentSwap` (blur→fade,
   единый паттерн).
7. SharedElement — через перепарентинг в `TransitionLayer`, не через
   снапшоты.
8. Компромисс: лучше меньше кода и понятнее, чем больше и «гибче».
9. Расширяемость: новый индикатор = один файл + регистрация в Registry.
   Новый модуль = одна папка + подключение в ModuleHost.
10. Все жесты (Quick Settings, Notification Center, Dashboard,
    Minimal-hold, Presentation Mode) регистрируют свои хитбоксы через
    `GestureZones.qml`, размеры и пороги которых читаются из Config.
